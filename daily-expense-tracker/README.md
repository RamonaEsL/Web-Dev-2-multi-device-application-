# SpendWise - Daily Expense Tracker

A simple single-page expense tracker built with React and Express.js.

## Features

- Add a daily expense
- View total spending and today's spending
- Search expenses
- Filter by category
- Delete an expense
- Responsive desktop, tablet, and mobile layout
- Express API with JSON file storage

## Run the project

1. Open this folder in VS Code.
2. Open a terminal and run:

```bash
npm install
```

3. Start the Express server:

```bash
npm run server
```

4. Open a second terminal and start React:

```bash
npm run client
```

5. Open `http://localhost:5173` in a browser.

The Express server runs on `http://localhost:3001`.
